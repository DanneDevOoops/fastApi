api.api_v1 module

API v1 Router

This module defines the API v1 router for the FastAPI application. It includes all routes interacting with the PostgreSQL database. The router is included in the main FastAPI application instance in the src/main.py module.

api.api_v1_ws_router module

API Web Sockets Router

This module defines the API v1 router for the FastAPI application. It includes all routes interacting through web sockets. The router is included in the main FastAPI application instance in the src/main.py module.
