api.v1_routes.application_routes module

Defines the Application API routes for the FastAPI v1 application.

This module provides endpoints for managing applications/services registered in the PostgreSQL database, including creation, retrieval, updating, and soft/hard deletion of application records.

api.v1_routes.user_routes module

Defines the User API routes for the FastAPI application (v1 – PostgreSQL).

Includes endpoints for creating users, retrieving single or multiple users (active and soft-deleted), updating user data (PUT & PATCH), soft deleting users, and permanently deleting users from the PostgreSQL database.
