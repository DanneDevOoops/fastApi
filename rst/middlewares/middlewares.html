middlewares.logger module

This module provides middleware for logging HTTP requests and responses in a FastAPI application.

It defines the LoggerMiddleware class, which logs incoming request details and outgoing response details using a configured logger. The logger is initialized based on application settings, allowing for customizable logging behavior. This middleware is intended to be added to the FastAPI middleware stack to enable consistent and centralized logging of API interactions for monitoring and debugging purposes.

Middleware for logging HTTP request and response details in a FastAPI application.

This middleware captures and logs information about each incoming HTTP request and its corresponding response using a configured logger. It is intended to be added to the FastAPI middleware stack to provide centralized logging for monitoring and debugging purposes.

Initialize the LoggerMiddleware with the given FastAPI application.

Retrieves application settings and initializes the logger based on the configured logger name. Sets up the middleware to intercept and log HTTP requests and responses.

Parameters:

app (FastAPI) – The FastAPI application instance to which this middleware is attached.
